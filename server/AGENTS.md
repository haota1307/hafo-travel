# Hướng dẫn cho AI làm việc trong repository

- Trước khi sửa code, đọc [documents/instructions/README.md](documents/instructions/README.md) và tài liệu liên quan được dẫn ở đó.
- Kiểm tra source thực tế trước khi kết luận. Không tự đặt nghiệp vụ, quyền truy cập, contract API hoặc cấu trúc khác với dự án.
- Test và code chỉ phục vụ test nằm trong `<projectRoot>/tests/`, tách khỏi `src/`.
- Giữ nguyên thay đổi đang có của người dùng; không reset, checkout hoặc xóa file ngoài phạm vi công việc.
